# Reglas activas verificadas

`firestore.active.rules` conserva las reglas publicadas y verificadas el 27 de octubre de 2026, después de activar el consecutivo de producción. Procedencia: candidato local de numeración, comparación byte por byte con la publicación remota.

El archivo raíz `firestore.rules` contiene trabajo previo y propuestas; no sustituye automáticamente esta instantánea. Antes de desplegar, comparar la versión remota actual y ejecutar las pruebas correspondientes. Subir este repositorio no despliega Firebase.

La aplicación requiere la configuración local `web/firebase-config.json`, excluida del repositorio; usar `web/firebase-config.example.json` como guía. Las exportaciones de datos, credenciales, evidencias y fotos locales permanecen fuera de Git. Las imágenes locales de productos no se recuperan al clonar el repositorio.
